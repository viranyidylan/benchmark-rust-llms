# Step 3 — Security module (SSRF guard + HMAC + limits)
Replace the `src/security.rs` stub with:

- `pub enum SecurityError` (thiserror): InvalidUrl, SchemeNotAllowed, CredentialsNotAllowed,
  UnresolvableHost, PrivateAddressBlocked, PayloadTooLarge — each with a clear Display message.
- `pub async fn validate_destination(url_str: &str, allow_private: bool) -> Result<Url, SecurityError>`:
  1. Parse with `url::Url`; must be absolute with scheme http or https, else InvalidUrl/SchemeNotAllowed.
  2. Host must be present. Username must be empty and password must be None (CredentialsNotAllowed).
  3. If `allow_private` is true, return Ok(url) after the structural checks above (skip IP checks).
  4. Collect candidate IPs: if host is an IP literal, just that one. If a domain, resolve with
     `tokio::net::lookup_host((host, port))` where port = 443 for https, 80 for http (or the URL's
     explicit port if present); DNS failure → UnresolvableHost.
  5. Reject (PrivateAddressBlocked) if ANY candidate IP is: loopback, private (RFC1918 + CGNAT
     100.64.0.0/10), link-local (incl. 169.254.0.0/16 — cloud metadata!), multicast, unspecified
     (0.0.0.0), or documentation ranges... actually: use a helper `fn ip_is_blocked(ip: &IpAddr) -> bool`
     that handles IPv4 via std `is_private/is_loopback/is_link_local/is_multicast/is_unspecified` PLUS
     an explicit check for 100.64.0.0/10 (std doesn't cover CGNAT); for IPv6 check loopback (::1),
     unspecified (::), link-local (fe80::/10), unique-local (fc00::/7), multicast (ff00::/8), and
     IPv4-mapped IPv6 (`to_ipv4_mapped()` then run the v4 check).
- `pub fn sign_body(secret: &str, body: &[u8]) -> String` using hmac+sha2+hex:
  `format!("sha256={}", hex::encode(mac.finalize().into_bytes()))`.
- `pub fn enforce_size(len: usize, max: usize) -> Result<(), SecurityError>` — PayloadTooLarge when len > max.
